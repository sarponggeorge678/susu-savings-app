My Susu App - Ghana Savings Tracker

A Susu savings app built on phone in Kumasi, Ghana.

Susu is how we save in Ghana - small deposits every week to reach a big goal. This app makes it digital.

What it does
- Set a savings goal (e.g. 41,495 GHS for Germany Ausbildung)
- Add deposit with amount + note (e.g. Mason work)
- See Total Saved + Remaining + Progress %
- See History of all deposits
- Lock App with password

How to use
1. Open `susu.html` in your phone browser
2. Set your goal
3. Add your first deposit
